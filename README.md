# Emir School President

Мобильный сайт-портфолио кандидата в президенты школы.

## Как открыть
Просто открой `index.html` в браузере.

## Код бонуса
По умолчанию: `2026`.

Чтобы изменить код, открой `index.html` и измени значение константы `code` внизу файла.

## Telegram
Ссылка сейчас: `https://t.me/marashtg`. При необходимости её можно заменить в `index.html`.

# Emir School President

Мобильный сайт-портфолио кандидата в президенты школы.

## Как открыть
Просто открой `index.html` в браузере.

## Код бонуса
По умолчанию: `2026`.

Чтобы изменить код, открой `script.js` и измени:
`const BONUS_CODE="2026";`
